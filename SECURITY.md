# Security Policy

## Reporting Security Vulnerabilities

If you discover a security vulnerability, please email security@example.com instead of using the issue tracker.

**Do not** create public GitHub issues for security vulnerabilities.

## Security Updates

We take security seriously and will:

1. Acknowledge receipt within 24 hours
2. Provide status updates every 5 days
3. Release patches for confirmed vulnerabilities

## Security Best Practices

For users:

- Use strong passwords (12+ characters)
- Enable 2FA if available
- Keep your browser updated
- Never share your authentication token
- Report suspicious activity

## Dependencies

We regularly update dependencies to patch known vulnerabilities. To check for vulnerabilities:

```bash
npm audit
```

## Compliance

- GDPR compliant data handling
- User data encryption at rest and in transit
- Regular security audits
- SOC 2 Type II certified (target)

## Contact

- Security Issues: security@example.com
- General Support: support@example.com
